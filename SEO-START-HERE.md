## 1. Set up Google Search Console first

This free tool shows how people find the site through Google: searches, impressions, clicks and indexed pages.

1. Open https://search.google.com/search-console with your Google account.
2. Add a **Domain** property: `therevenueinbox.com`, without https or www.
3. Google will give you a DNS TXT verification record. Send that record here, or add it at the provider that manages the domain's DNS. It is a public verification record, not a password.
4. Return to Google and click Verify after the record is in place.
5. Open Sitemaps and submit `https://www.therevenueinbox.com/sitemap.xml`.

If DNS verification is inconvenient, a URL-prefix property for `https://www.therevenueinbox.com/` supports an HTML verification tag. Send the exact tag and it can be added to the live site separately. It covers that URL prefix rather than all domain variations.

Data takes time to accumulate. A new property with no reports is not evidence that the site is broken. Don't send a Google password, private key or recovery code.

Google instructions: https://support.google.com/webmasters/answer/9008080?hl=en

## 2. Add Google Analytics when the property is ready

Search Console covers Google search. Google Analytics 4 can measure website visits and actions from other sources too.

1. Open https://analytics.google.com and create an account/property for The Revenue Inbox.
2. Add a Web data stream for `https://www.therevenueinbox.com`.
3. Copy the **Measurement ID**, which starts with `G-`, and send it here. It is an identifier, not your login.
4. We can then add and verify the tracking setup before calling its reports reliable. Configure collection/consent settings for the actual site and audience rather than copying a generic setup blindly.

A booking-button click is not a completed appointment. The current direct Calendly iframe is useful for booking but is not a verified completion-tracking integration. Calendly documents its JavaScript embed event or an account/webhook integration for that step. We will connect completion signals, then distinguish booked calls from qualified/attended calls in reporting. No tracking provider was added in this build.

Google instructions: https://support.google.com/analytics/answer/9304153?hl=en
Calendly instructions: https://calendly.com/help/advanced-calendly-embed-for-developers
