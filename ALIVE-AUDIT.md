## Tool findings and narrow exceptions

The unmodified raw taste reports are retained. Final source lint: 0 FAIL, 0 WARN, with inline reasons for brief-authorized grid, physical UI shadows and functional software separators.

Rendered inspector allowances are specific:

- `palette-purple`: the user requires #8A40EA and its tints/shades. Replacing it would violate the brief.
- `headline-lines`: the complete hero outcome/deadline/recourse is intentionally three visual lines. Other overlong problem and final headings were shortened.
- `icon-cards`: this classifier mistakes the three result-led campaign rows with their contextual graphics for icon feature cards. They contain exact investor, meeting and reply encodings, not generic feature icons.
- `eyebrow`: the classifier mistakes a preceding “Read the campaign” action for a label above the next numeric result. It is a real link belonging to the previous evidence group.

The final rendered raw report retains one `covered-text` finding at 390px: naturally scrolling headings pass underneath the sticky header/mobile booking bar at two sampled scroll positions. These are transient viewport-edge overlaps from the explicitly requested sticky action, not a permanent clipped block or an overlay on the hero. All content can be scrolled fully into view and anchor offsets clear the header. This finding is documented rather than suppressing it in the raw report.

Two warnings are accepted: `no-footage` does not detect the five intentional click-to-load Vimeo facades; eager video would violate the brief. `size-count` includes small software UI and the existing seven semantic editorial roles; these remain tokenized and readable rather than forcing all software chrome into body size.

Impeccable's 12 cramped-padding findings were verified against actual padded containers and UI rows. They are nested-container/CSS-variable false positives. Its aphoristic-cadence flag describes the explicit outcome/timeframe/guarantee hero. Its derived-color advisory describes the intentional ui-line mix within the approved palette. No detector files were altered to change results.
